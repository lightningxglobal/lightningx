## 4. Vault 集成 — 不需要（已被文件 secret 覆盖）

**Vault 是什么**：HashiCorp Vault，一个集中式密钥/凭据管理服务——
应用启动时向它请求数据库密码、JWT 签名密钥等，而不是写在配置里；
还支持密钥轮换、租约、审计。属于"企业级密钥基础设施"。

**为什么我们暂时不需要**：Vault 解决的核心问题（密钥不落地为明文环境变量）
已经被**文件 secret**（`*_FILE`，`f0d7070`）解决——Docker/K8s 把密钥挂载为
tmpfs 文件，应用从文件读，不经过环境变量（环境变量会泄漏到
`/proc/<pid>/environ` 和崩溃转储）。这覆盖了绝大多数容器部署场景，零额外基础设施。

**何时才真需要 Vault**：要做**自动密钥轮换**、**动态短期数据库凭据**、
或公司已统一用 Vault 管理所有服务密钥时。届时在 `secret_from_env_or_file` /
`database_url_from_env` 旁边加一个 Vault 后端即可，接口已留好。
